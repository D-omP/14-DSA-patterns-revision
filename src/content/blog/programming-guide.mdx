# Clean Code: Best Practices for Modern JavaScript

After years of writing and reviewing code, I've learned that clean code is about making life easier for the next developer (often yourself).

## Core Principles

1. **Clarity Over Cleverness**
2. **Single Responsibility**
3. **Meaningful Names**

## Code Examples

```javascript
// Bad
const x = arr.map(a => a.b).filter(b => b > 0);

// Good
const activeUsers = users
  .map(user => user.lastLoginDate)
  .filter(date => isWithinLastWeek(date));
```
