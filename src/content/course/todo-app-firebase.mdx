## Introduction

In the world of modern web development, creating a robust, real-time todo application requires a powerful backend infrastructure. Firebase provides an all-in-one solution that simplifies development and scales effortlessly. This comprehensive guide will walk you through building a full-featured Todo app using Firebase, React, and best practices.

## Prerequisites

Before we begin, ensure you have:
- Node.js (v14+ recommended)
- npm or Yarn
- Basic knowledge of React
- A Google account for Firebase setup

## Step 1: Firebase Project Setup

### Creating a Firebase Project
1. Navigate to [Firebase Console](https://console.firebase.google.com/)
2. Click "Add project"
3. Choose a project name
4. Enable Google Analytics (optional)

### Firebase Configuration
After project creation, you'll need to:
- Enable Authentication (Google Sign-In)
- Create Firestore Database
- Set up Firebase Web App configuration

### Firebase Services We'll Use
- Authentication
- Firestore Database
- Hosting (optional deployment)

## Step 3: Firebase Configuration

```javascript
// src/firebase.js
import { initializeApp } from 'firebase/app';
import { getFirestore } from 'firebase/firestore';
import { getAuth, GoogleAuthProvider } from 'firebase/auth';

const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_PROJECT_ID.firebaseapp.com",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "YOUR_PROJECT_ID.appspot.com",
  messagingSenderId: "YOUR_MESSAGING_SENDER_ID",
  appId: "YOUR_APP_ID"
};

// Initialize Firebase
const app = initializeApp(firebaseConfig);
export const db = getFirestore(app);
export const auth = getAuth(app);
export const googleProvider = new GoogleAuthProvider();
```

## Step 4: Authentication Component

```jsx
import React from 'react';
import { signInWithPopup } from 'firebase/auth';
import { auth, googleProvider } from './firebase';

function Authentication() {
  const signInWithGoogle = async () => {
    try {
      const result = await signInWithPopup(auth, googleProvider);
      console.log('Authenticated User:', result.user);
    } catch (error) {
      console.error('Authentication Error:', error);
    }
  };

  return (
    <div>
      <button onClick={signInWithGoogle}>
        Sign In with Google
      </button>
    </div>
  );
}
```

## Step 5: Firestore Todo Operations

```jsx
import React, { useState } from 'react';
import { 
  collection, 
  addDoc, 
  updateDoc, 
  deleteDoc, 
  doc 
} from 'firebase/firestore';
import { db, auth } from './firebase';

function TodoList() {
  const [todoText, setTodoText] = useState('');

  // Add Todo
  const addTodo = async () => {
    if (!todoText.trim()) return;

    await addDoc(collection(db, 'todos'), {
      text: todoText,
      completed: false,
      userId: auth.currentUser.uid,
      createdAt: new Date()
    });

    setTodoText('');
  };

  // Update Todo Status
  const toggleTodoStatus = async (todoId, currentStatus) => {
    const todoRef = doc(db, 'todos', todoId);
    await updateDoc(todoRef, {
      completed: !currentStatus
    });
  };

  // Delete Todo
  const deleteTodo = async (todoId) => {
    const todoRef = doc(db, 'todos', todoId);
    await deleteDoc(todoRef);
  };

  return (
    <div>
      <input 
        value={todoText}
        onChange={(e) => setTodoText(e.target.value)}
        placeholder="Enter todo item"
      />
      <button onClick={addTodo}>Add Todo</button>
    </div>
  );
}
```

## Step 6: Real-time Todo Fetching

```jsx
import React, { useState, useEffect } from 'react';
import { 
  collection, 
  query, 
  where, 
  onSnapshot, 
  orderBy 
} from 'firebase/firestore';
import { db, auth } from './firebase';

function TodoList() {
  const [todos, setTodos] = useState([]);

  useEffect(() => {
    // Real-time listener for user's todos
    const q = query(
      collection(db, 'todos'),
      where('userId', '==', auth.currentUser.uid),
      orderBy('createdAt', 'desc')
    );

    const unsubscribe = onSnapshot(q, (querySnapshot) => {
      const todoList = querySnapshot.docs.map(doc => ({
        id: doc.id,
        ...doc.data()
      }));
      setTodos(todoList);
    });

    // Cleanup subscription
    return () => unsubscribe();
  }, []);

  return (
    <div>
      {todos.map(todo => (
        <div key={todo.id}>
          {todo.text}
          <input 
            type="checkbox" 
            checked={todo.completed}
            onChange={() => toggleTodoStatus(todo.id, todo.completed)}
          />
          <button onClick={() => deleteTodo(todo.id)}>Delete</button>
        </div>
      ))}
    </div>
  );
}
```

## Security Considerations

### Firestore Security Rules
```firestore
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /todos/{todoId} {
      allow read, write: if request.auth != null && 
                          request.auth.uid == resource.data.userId;
    }
  }
}
```
