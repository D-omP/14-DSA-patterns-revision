## Cyclic Sort Pattern

The Cyclic Sort pattern is an efficient technique for sorting numbers in a given range. It's particularly useful when dealing with numbers from 1 to n or 0 to n-1.

### When to use Cyclic Sort?
- Array contains numbers in range 1 to n
- Finding missing numbers
- Finding duplicate numbers
- Array permutation problems
- In-place sorting requirements

### How it Works
1. Each number should be at index (number - 1)
2. Swap numbers until each is in correct position
3. Iterate through array to find anomalies

### Basic Template
```python
def cyclicSort(nums):
    i = 0
    while i < len(nums):
        correct_pos = nums[i] - 1  # For 1 to N
        # correct_pos = nums[i]    # For 0 to N-1
        
        if nums[i] != nums[correct_pos]:
            nums[i], nums[correct_pos] = nums[correct_pos], nums[i]
        else:
            i += 1
    return nums
```

### Common Variations
1. **Find Missing Number**
```python
def findMissing(nums):
    i = 0
    while i < len(nums):
        correct_pos = nums[i]
        if nums[i] < len(nums) and nums[i] != nums[correct_pos]:
            nums[i], nums[correct_pos] = nums[correct_pos], nums[i]
        else:
            i += 1
    
    # Find first number not in correct position
    for i in range(len(nums)):
        if nums[i] != i:
            return i
    return len(nums)
```

2. **Find Duplicate Number**
```python
def findDuplicate(nums):
    i = 0
    while i < len(nums):
        correct_pos = nums[i] - 1
        if nums[i] != nums[correct_pos]:
            nums[i], nums[correct_pos] = nums[correct_pos], nums[i]
        else:
            if i != correct_pos:
                return nums[i]
            i += 1
    return -1
```

### Key Points
1. Time Complexity: O(n)
2. Space Complexity: O(1)
3. Modifies input array
4. Best for specific number ranges
5. Useful for finding array problems
