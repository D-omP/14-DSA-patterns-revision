## Sliding Window Pattern

The Sliding Window pattern is used to perform operations on arrays or strings using a window that slides through the data structure. This technique is particularly useful for solving problems that involve contiguous sequences.

### When to use Sliding Window?
- Finding subarrays/substrings that satisfy certain conditions
- Calculating running averages
- Finding max/min sum subarrays of fixed size
- Finding longest/shortest substring with certain properties

### Types of Sliding Window
1. **Fixed Window Size**
    - Window size remains constant throughout
    - Example: Find max sum subarray of size K

2. **Variable Window Size**
    - Window size changes based on conditions
    - Example: Longest substring without repeating characters
