## Depth First Search Pattern

DFS is a traversal technique that explores as far as possible along each branch before backtracking. It's particularly useful for exploring paths and tree-like structures.

### When to use DFS?

* Path finding problems
* Tree/Graph traversal
* Cycle detection
* Topological sorting
* Maze solving

### How it Works

1. **Basic Concept**
    * Use recursion or stack
    * Explore one path completely
    * Backtrack when needed

2. **Key Steps**
    * Process current node
    * Recursively process children
    * Backtrack to parent

### Basic Template

```python
def dfs(root):
    if not root:
        return
    
    # Process current node
    print(root.val)
    
    # Recurse on children
    dfs(root.left)
    dfs(root.right)
```

### Common Variations

1. **Iterative DFS**

```python
def dfsIterative(root):
    if not root:
        return []
    
    result = []
    stack = [root]
    
    while stack:
        node = stack.pop()
        result.append(node.val)
        
        # Add right first so left is processed first
        if node.right:
            stack.append(node.right)
        if node.left:
            stack.append(node.left)
    
    return result
```

2. **Path Finding**

```python
def hasPath(root, target_sum, current_sum=0, path=[]):
    if not root:
        return False
    
    current_sum += root.val
    path.append(root.val)
    
    if not root.left and not root.right:
        if current_sum == target_sum:
            return True
    
    if (hasPath(root.left, target_sum, current_sum, path) or
        hasPath(root.right, target_sum, current_sum, path)):
        return True
    
    path.pop()  # Backtrack
    return False
```

### Edge Cases to Consider

1. Empty tree/graph
2. Single node
3. Unbalanced trees
4. Cycles in graphs
5. Disconnected components
6. All nodes same value
7. Maximum depth limit

### Tips

1. Consider iterative vs recursive approach
2. Watch for stack overflow
3. Track visited nodes in graphs
4. Use backtracking when needed
5. Handle base cases properly

### Time & Space Complexity

* Time Complexity: O(V + E) for graphs, O(n) for trees
* Space Complexity: O(h) where h is height
* Recursive call stack can grow large
* Better space complexity than BFS for deep structures
